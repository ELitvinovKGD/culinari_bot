# Backlog

Здесь хранятся идеи и задачи проекта, которые ещё не реализованы.
Подробное описание версии 0.1 — в `product.md`.

## Обозначения

- `MVP Core` — без этого заказ не проходит от начала до конца. Делаем первым.
- `MVP Operations` — удобство реальной работы. Делаем вторым заходом.
- `Production` — необходимо перед реальным запуском.
- `Later` — последующее развитие.
- `Idea` — требует обсуждения.

## MVP Core

- [ ] Каталог карточек блюд: эмодзи, название, описание, порция текстом, цена, фото; архивирование вместо удаления.
- [ ] Выпуск: название, шапка, текст после списка, позиции из каталога или новые блюда.
- [ ] Цена, порция и описание позиции настраиваются отдельно для выпуска.
- [ ] Заказ сохраняет название, порцию и цену на момент оформления.
- [ ] Состояния выпуска: черновик → открыт → закрыт → завершён; открыт только один.
- [ ] Публикация поста выпуска в группу (альбом / фото / текст, кнопка или ссылка «Заказать»).
- [ ] Подключение группы командой `/connect`.
- [ ] Карусель карточек у клиента с −/+.
- [ ] Полный список блюд с −/+ и экран «Итого».
- [ ] Корзина в базе, очищается при закрытии приёма.
- [ ] Данные клиента: имя, телефон, доставка/самовывоз, адрес, комментарий; сохранение и подтверждение при повторном заказе; автоматический `@username`.
- [ ] Номер заказа (сквозной), несколько заказов клиента в одном выпуске.
- [ ] Админка: список заказов выпуска, статусы Принят → Доставлен / Отменён.
- [ ] Уведомление шефа о новом заказе.
- [ ] Закрытие приёма с текстом о доставке и рассылкой клиентам выпуска.
- [ ] Excel: лист «Производство» (блюда × клиенты, итог) и лист «Доставка». Пример таблицы пришлёт Евгений.
- [ ] Docker Compose: бот + PostgreSQL; миграции.
- [ ] Тесты основной логики заказов.

## MVP Operations

- [ ] «Мои заказы» и отмена клиентом до доставки с уведомлением шефа.
- [ ] Анонимный пост в группу о каждом заказе; редактируемые шапка и концовка.
- [ ] Удаление поста о заказе при полной отмене, если ему меньше 48 часов.
- [ ] Готовый пост для ручной пересылки, если публикация в группу не удалась.
- [ ] Правка открытого выпуска с уведомлениями клиентов: цена (с выбором применения к оформленным заказам), описание, порция, снятие с продажи, новое блюдо.
- [ ] Обновление поста выпуска в группе по кнопке.
- [ ] Своя позиция шефа в заказе с уведомлением клиента.
- [ ] Кнопка «Лишние порции» и пост с «Написать шефу».
- [ ] Настройки самовывоза: вкл/выкл и адрес.
- [ ] Переключатели уведомлений у каждого админа.
- [ ] Добавление админов по одноразовой ссылке.
- [ ] Уведомление о личных данных и команда `/delete_me`.
- [ ] Инструкция для шефа `docs/chef-guide.md`.

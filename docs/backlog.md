# Backlog

Здесь хранятся идеи и задачи проекта, которые ещё не реализованы.
Подробное описание версии 0.1 — в `product.md`.

## Обозначения

- `MVP Core` — без этого заказ не проходит от начала до конца. Делаем первым.
- `MVP Operations` — удобство реальной работы. Делаем вторым заходом.
- `Production` — необходимо перед реальным запуском.
- `Later` — последующее развитие.
- `Idea` — требует обсуждения.

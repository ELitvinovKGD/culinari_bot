## Первый запуск и настройка (решения от 25.11)

Шеф настраивает бота сам, с телефона, без разработчика рядом.

- [x] **Мастер первой настройки.** При первом входе в админку бот ведёт по шагам:
  1. Подключить группу — инструкция прямо в шаге (добавить бота → сделать админом
     с правом удалять сообщения → написать `/connect`); бот ждёт подключения
     и сам переходит дальше.
  2. Контакт для клиентов (@username шефа).
  3. Самовывоз: будет или нет; если да — адрес.
  4. Подсказка: «Заведите первое блюдо» → «Соберите первый выпуск».
  Мастер можно прервать — продолжить из чек-листа.
  ✅ Сделано (тексты подсказок — финализировать с шефом).
- [x] **Чек-лист готовности** вверху главного экрана админки: каждый пункт ✅/⚠️
  и кнопка к нужной настройке. Обязательные: группа, контакт, адрес самовывоза
  (если самовывоз включён). Сворачивается в «Лавка настроена ✅», когда
  обязательное заполнено И есть хотя бы одно блюдо и один выпуск.
  ✅ Сделано.
- [ ] **Порядок передачи бота шефу:** сервер (владелец — Евгений) → ссылка-приглашение
  шефу → шеф проходит мастер на тестовой группе и делает пробный выпуск →
  тестовый заказ вдвоём, смотрим Excel → `/connect` в настоящей группе →
  первый настоящий выпуск → позже передача владения через BotFather.
- [ ] **Инструкция:** короткие подсказки внутри бота (мастер, чек-лист, примеры
  в вопросах) + полная версия в `docs/chef-guide.md`. Финальные тексты — после
  того, как всё утрясём с Евгением и шефом. Отдельной кнопки «Помощь» не делаем.
- Приоритет (🔴 или нет) — решим после того, как Евгений сам прогонит заказы.
- [x] **Закрытие приёма и объявление выдачи склеены в одну кнопку**, а у шефа это
  разные моменты с разницей в дни («приём закрывается» → «всё готово, развожу во вторник»).
  ✅ Решили (25.11):
  1. «🔒 Закрыть приём» только останавливает заказы; клиенты получают короткое
     автоматическое «Приём заказов закрыт, ваш заказ принят в работу» — без текста шефа.
  2. Новая кнопка «📣 Объявить выдачу» в закрытом выпуске: шеф пишет текст, каждый
     клиент получает текст + свой заказ и сумму + (самовывоз) адрес + «✉️ Написать
     шефу». Можно нажимать повторно («Задерживаюсь на час»).
  3. Если есть клиенты на самовывозе — два текста по очереди: для доставки и для
     самовывоза. Все на доставке — один вопрос.
  4. «🚚 Доставлен» — клиенту ничего не приходит. Позже здесь может появиться
     сбор отзывов (см. backlog → Later).
  ✅ Сделано: «🔒 Закрыть приём» + «📣 Объявить выдачу».

## 2026-11-25 — Код v0.1

- **Модульный монолит, три слоя** (`bot/` → `services/` → `db/`).
  Правила живут в `services/` и не знают про Telegram — их можно тестировать
  без бота и переиспользовать для микросайта. Общее «ядро» под другие бизнесы
  не выделяем, пока нет второго проекта.
- **Long polling, а не webhook.** Не нужен публичный адрес и HTTPS;
  одинаково работает локально и на Oracle.
- **FSM в памяти (MemoryStorage).** При перезапуске теряется только
  незаконченный ввод данных; корзина хранится в базе. Redis для нашего
  масштаба — лишняя сложность.
- **Деньги в центах (int).** float неточен.
- **Снимки данных** в позициях выпуска и заказа — история не меняется задним числом.
- **Тесты на SQLite в памяти** + переменная `TEST_DATABASE_URL` для прогона на PostgreSQL.
- **Сквозной тест с поддельным Telegram** (`tests/test_bot_flow.py`) — ловит ошибки
  в кнопках и обработчиках без запуска настоящего бота.
